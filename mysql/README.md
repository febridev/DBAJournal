# MySQL Administration

Guides and scripts for managing MySQL on Ubuntu.

## Contents
- **Patching**: Script for pre-patching checks (`mysql_pre_patch_check.sh`).
- **Replication**: Guides for both InnoDB and Logical replication (`mysql-innodb-replication-ubuntu.md`, `mysql-logical-replication-ubuntu.md`).
- **Routing**: Installation and configuration guide for MySQL Router (`mysql-mysql-router-ubuntu.md`).
