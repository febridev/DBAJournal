# Oracle Database Administration

Comprehensive resources for Oracle Database, including 19c installation, high availability, and automation.

## Sections
- **Installation & Setup**: Guides for DB installation, PDB setup, and Grid Infrastructure.
- **High Availability**: RAC installation, DataGuard configuration, and switchover procedures.
- **Maintenance**: Patching guides and parameter change logs.
- **Automation**: 
  - [Ansible Oracle Restart](./ansible/oracle_restart): Automated standalone installation.
- **Utilities**: Helper scripts for RAC and Grid verification.
- **Error Collection**: Documentation of encountered errors and their resolutions.
