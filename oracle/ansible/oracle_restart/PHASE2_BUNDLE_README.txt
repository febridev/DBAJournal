# PITFALL ENCODING (why tasks look the way they do)
# =============================================================================
# 1. rc=6 from gridSetup.sh == "install ok, waiting for root scripts" ->
#    failed_when: rc not in [0, 6]
# 2. -applyRU persists into .patch_storage EVEN IF rsp validation later fails
#    (INS-10105) -> re-run must use plain -silent (task 2.5 probe).
# 3. rsp keys are XSD-strict: use AUSize (MB), EXTERNAL uppercase,
#    configureGIMRDataDG; NO configureCAD/configureAFS/OSGROUP/useIPMI.
# 4. CREATE DISKGROUP AU syntax: ATTRIBUTE 'au_size'='4M' (plain 'AU SIZE 4M'
#    => ORA-00933).
# 5. udev SYMLINK owner is always root:root; ownership lands on the block dev
#    -> verify with ls -lL (dereference).
# 6. -waitForCompletion defers ASM diskgroup config to
#    gridSetup.sh -executeConfigTools (must run AFTER root.sh, as grid).
